About Infineon Technologies

Role Overview

The title is Young Graduate Trainee, and the work described is that of an SVT Engineer. In this role you validate Wi-Fi software so that Wi-Fi products meet high standards of performance, reliability and interoperability across different environments.

You will work with cross-functional teams, including firmware developers, product managers and test teams. That makes the role a good way to learn how a product moves from firmware development to a validated release.

Key responsibilities

  • Test and validate Wi-Fi protocol features based on IEEE 802.11 standards.
  • Execute manual and automated test cases for wireless networking products.
  • Analyse Wi-Fi packet captures using tools like Wireshark.
  • Identify, log and track software defects using bug tracking tools.
  • Validate wireless features such as authentication, roaming, throughput, security protocols (WPA/WPA2/WPA3) and power saving.
  • Work closely with development and QA teams to reproduce and debug issues.
  • Prepare test reports and maintain test documentation.
  • Participate in interoperability and regression testing.

Skills That Will Help

The posting lists duties rather than a long tool checklist, so your resume should show evidence for these areas:

  • Networking basics: the OSI model, TCP/IP, and how Wi-Fi differs from wired Ethernet.

Preparation Plan

You can build solid readiness in two to three weeks if you start from your college fundamentals.

Week 1: Wireless fundamentals

  • Revise the OSI layers, with focus on the data link and physical layers.
  • Understand the 802.11 basics: SSID, BSSID, channels, beacons, association and authentication.
  • Learn what WPA, WPA2 and WPA3 do at a high level.

Week 2: Hands-on practice

  • Install Wireshark and capture traffic on your own Wi-Fi network.
  • Practise filtering by frame type and identifying the connection handshake.
  • Test throughput between two devices using a free tool and note what changes with distance and interference.

Week 3: Testing and scripting

  • Learn how to write a good test case: steps, expected result and actual result.
  • Practise writing a clear bug report with reproduction steps.
  • Write a small Python script that automates a repeatable check.
