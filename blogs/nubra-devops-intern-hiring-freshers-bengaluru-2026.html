Nubra DevOps Intern 2026

Nubra is hiring a DevOps Intern in the Greater Bengaluru Area, and the role is a hands-on one. The posting says you will own real tasks in production-grade environments from your first weeks.

This guide covers what the role involves, the skills Nubra asks for, how to apply and how to prepare. One thing to know up front: the must-have list is demanding for a fresher, so a visible project matters more than a certificate.

About Nubra

Nubra describes itself as an all-in-one trading platform built for every kind of trader, from stock scalpers to options strategists. It combines an advanced option chain, a multi-leg strategy builder, live market scanners, institutional-grade charts and in-depth research. Nubra is a product of Zanskar Securities Pvt Ltd, and more information is available at nubra.io.

For a DevOps intern, this context matters. A trading product has users who are sensitive to delays and outages, so reliability, speed and security are daily concerns. You will learn how infrastructure is treated when downtime has a real cost, which is useful experience for any later DevOps or SRE role.

Role Overview

The posting states that trading platforms have no room for downtime. As an intern, you work alongside the infrastructure team on the systems that keep Nubra fast, reliable and secure. The listed responsibilities are:

  • Provision and manage virtual machines and containers, and keep environments consistent and reproducible.
  • Write and optimise Dockerfiles and Compose setups, and help containerise services for deployment.
  • Automate repetitive operational work with Bash or Python scripts.
  • Build and improve CI/CD pipelines so code moves from commit to production safely.
  • Set up and extend monitoring, dashboards and alerts, and help investigate incidents.
  • Troubleshoot Linux systems and networking issues across the stack.
  • Document what you build so the rest of the team can run it.

The last point is easy to overlook. Good documentation is a core DevOps habit, and you can show it in your application through clear READMEs in your projects.

Eligibility and Skills Required

Nubra does not list a degree, branch or passout year in the posting we reviewed, so those are not disclosed. What it lists in detail is skills. The must-have items are:

  • Linux: processes, systemd, file permissions, logs, package management and command-line troubleshooting.
  • Networking: TCP/IP, DNS, HTTP/HTTPS, TLS, ports, routing and load balancing.
  • Virtualisation: hypervisors, VMs versus containers, virtual networking (bridges, VLANs), virtual disks and storage.
  • Git: branching strategies, merge requests, rebasing and resolving conflicts.
  • Docker: optimised Dockerfiles, multi-stage builds, Docker Compose, volumes and networks.
  • Scripting: Bash or Python to automate real operational tasks.
  • Project proof: at least one substantial project (homelab, internship or GitHub repo) where you built, deployed and monitored something end to end.

Good to have

These will make your profile stand out but are not mandatory:

  • Proxmox VE: VMs, LXC containers, templates, cloud-init, snapshots and backups.
  • Storage knowledge: ZFS, LVM or Ceph.
  • Kubernetes: Pods, Deployments, Services, Ingress, ConfigMaps/Secrets and debugging workloads.
  • Terraform and/or Ansible, including the Terraform Proxmox provider.
  • CI/CD in GitLab CI, GitHub Actions or Jenkins.
  • Prometheus and Grafana, including PromQL, dashboards and alerts.
  • AWS or GCP basics: EC2, S3, IAM, VPC. A cloud certification is a plus.
  • PostgreSQL querying, backups and replication concepts.
  • Ability to read and write Go.

You do not need every good-to-have item, but you do need the must-haves and one real project to point to.

Stipend

The LinkedIn job alert for this listing shows ₹40K-₹60K per month. The employer's posting text does not state the figure, so treat it as the reported range and confirm the exact amount, duration and any conversion to a full-time role during the interview. Where you land in the range will likely depend on your skills and project depth.

How to Apply

  1. Open the employer's LinkedIn posting through the link in the Official Links section below.
  2. Log in to LinkedIn and check that your profile shows your education, skills and project links.
  3. Click Easy Apply and attach an updated one-page resume.
  4. Put your GitHub link and any homelab write-up or project documentation near the top of the resume.
  5. Answer any screening questions honestly, especially about Linux, Docker and Git.
  6. Submit, then keep an eye on LinkedIn messages and your email for the next step.

Make your project easy to find

Recruiters spend seconds on each resume. Give your best DevOps project its own line with a one-sentence outcome, such as "Deployed a three-service app with Docker Compose, CI pipeline and Grafana dashboards," followed by the repo link.

Selection Process

The selection process is not disclosed. Based on the must-have list, expect a resume screen focused on projects, followed by a technical conversation with the infrastructure team. Be ready to discuss your own project in depth, since the posting asks for proof that you built, deployed and monitored something end to end. A short practical or troubleshooting exercise on Linux or Docker would not be surprising, but this is an expectation, not a confirmed step.

Preparation Plan

If you have a week or two before an interview, a focused plan works better than reading everything.

Linux and networking

  • Practise from the command line: checking processes, reading logs with journalctl, managing services with systemctl, fixing file permissions and installing packages.
  • Be able to explain what happens when you type a URL: DNS lookup, TCP handshake, TLS, HTTP request and load balancer.
  • Know the difference between common ports, and how to test connectivity with tools like curl, ping, traceroute and ss.

Docker and Git

  • Write a multi-stage Dockerfile for a small app and explain why it reduces image size.
  • Build a Compose file with an app, a database and a volume, and connect them over a custom network.
  • Rehearse rebasing, resolving a merge conflict and explaining merge versus rebase.

Scripting, CI/CD and monitoring

  • Write a Bash or Python script that does something real, such as rotating logs, checking service health or backing up a database.
  • Create a simple pipeline in GitHub Actions that builds an image and runs tests.
  • Run Prometheus and Grafana locally, scrape a metric, build a dashboard and set one alert.

Interview Topics to Revise

  • VMs versus containers, and when you would pick each.
  • How a container is isolated, and what happens to data when it is removed.
  • What a reverse proxy and a load balancer do.
  • How you would investigate a server that is suddenly slow.
  • How a TLS certificate is checked and what an expiry failure looks like.
  • What makes a deployment safe: rollbacks, health checks and staged releases.
  • Your own project: why you chose each tool, what broke and how you fixed it.

Build a Homelab Project

The posting names homelab projects explicitly, so a small one is a smart investment. A practical idea: run two or three VMs or containers, host a simple web service with a database, put a reverse proxy in front, add a CI pipeline for deployments, and monitor it with Prometheus and Grafana. If you want to touch the good-to-have list, try Proxmox for the VMs and Ansible or Terraform to provision them. Document the setup in a README with a diagram and the problems you solved.

Common Mistakes to Avoid

  • Listing tools you cannot explain. If you write Kubernetes or Terraform, expect questions on it.
  • Submitting with no project link. The posting asks for a substantial project, so missing proof weakens your application.
  • Skipping networking basics. DNS, TLS and ports are must-haves and often decide technical rounds.
  • Copy-pasting tutorials without understanding. Be ready to explain why each line exists.
  • Ignoring documentation. The role asks you to document your work, so show it in your repos.
  • Waiting too long. No deadline is disclosed, so do not assume there is time.

This is a rare internship where you may work on infrastructure behind a live trading platform, with mentorship and a reported stipend of ₹40K-₹60K per month. The bar is real, though: Nubra expects solid Linux, networking, Docker and Git skills plus one end-to-end project. If you already have those, apply through LinkedIn Easy Apply now. If not, spend a few focused days on a small homelab project, document it well and then apply.
