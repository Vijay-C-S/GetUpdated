Infineon Junior Software Developer (Contract) opening in Bangalore

About Infineon Technologies

Infineon is a global semiconductor company that makes power systems, automotive chips, security solutions and IoT components. Its engineers design complex chips, and that work depends heavily on software: simulation tools, scripts, build systems and data pipelines that connect everything.

In Bangalore, Infineon runs a large engineering centre. Software roles here often support chip design and verification teams, so even a "software developer" job lets you see how silicon is actually designed.

Role Overview: What You Will Do

The team is modernising Infineon's toolchain so it runs the same way on Linux, Windows (WSL2) and high-performance compute environments. According to the official posting, your work would include:

  • Writing and maintaining backend code and command-line interfaces in Python and/or C++.
  • Refactoring legacy scripts to run on both Windows (WSL2) and Linux, replacing hardcoded OS dependencies with environment variables.
  • Working with JSON, XML and YAML so that simulation tools can exchange data automatically.
  • Writing validation scripts ("linters") that run in Jenkins CI/CD pipelines to catch errors and enforce coding standards.
  • Improving internal tool usability with clear error messages and fix hints.
  • Writing unit tests and helping with automated stress tests.

Most of this is the unglamorous but valuable work of making tools reliable. It teaches habits that carry over to any software career.

Eligibility Criteria

  • ✅ Bachelor's or Master's degree in Computer Science, Computer Engineering, Electrical Engineering or a related field.
  • ✅ Recent graduate, or 1-2 years of experience.
  • ✅ Solid foundations in Python and/or C++.
  • ✅ Comfortable with Linux and Windows command lines.
  • ✅ Familiarity with Git and basic CI/CD concepts.
  • ✅ Basic knowledge of YAML and JSON configuration files.
  • ✅ Familiarity with Windows Subsystem for Linux (WSL).
  • ✅ A strong problem-solving mindset and eagerness to learn.

Nice to have: basic knowledge of EDA tools, SystemC or hardware simulation workflows, and experience with bash scripts or build automation tools.

The degree list is broad, so ECE and EEE graduates with solid scripting skills are a good fit. Some aggregator pages list B.Sc and M.Sc as well, but check the exact wording on the official posting before you apply.

Contract Terms and Salary

The official posting describes the job as a temporary contract under a third-party payroll partner. Benefits are set by that partner, not by Infineon directly. That means you should not expect the full Infineon employee package.

No salary figure is published on the official page. Some aggregator listings say "best in industry", which is not a number. Ask the recruiter about compensation, contract duration, extension possibility and conversion chances during the first call.

Contract role, so ask early

Confirm the payroll partner's name, contract length, notice period and benefits before accepting an offer. A clear answer here saves surprises later.

Selection Process

Infineon does not publish the selection steps for this posting. For similar technical roles, candidates commonly go through a resume screen, one or more technical interviews and an HR discussion, but treat that as a general expectation, not a confirmed process.

Because the job is about tooling and scripting, expect questions on your own projects, Python or C++ basics, Linux commands and Git workflows.

Likely Interview Topics

  • What CI/CD means and what a Jenkins pipeline does.
  • Python data structures, exceptions and testing.

Show tooling mindset
